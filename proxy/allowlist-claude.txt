# -----------------------------------------------------------------------------
#  REQUIRED
# -----------------------------------------------------------------------------

#  The Claude API itself: every request the agent makes to the model.
#  Also used by WebFetch, which asks Anthropic to check a destination's
#  reputation before fetching it.
^api\.anthropic\.com$

#  Renewing your login.
#
#  Do not remove this thinking it is optional. Your access token expires about
#  once an hour, and the renewal goes to THIS host, not to api.anthropic.com.
#  Without it, a session works beautifully for roughly an hour and then dies in
#  a way that looks like a proxy fault.
^platform\.claude\.com$


# -----------------------------------------------------------------------------
#  OPTIONAL
# -----------------------------------------------------------------------------

#  Claude Code's own documentation. These are now also in
#  allowlist-common.txt, so all three commands can read them. The lines are
#  kept here too; a repeated line costs nothing.
^code\.claude\.com$
^claude\.com$

#  The login page, for /login inside the sandbox. The sandbox has its own login,
#  kept in history/claude/credentials.json, and this is how you make it the
#  first time. Needed; see seed_credentials() in safer-claude.
^claude\.ai$
